# 🐝 Academia FitZone

Aplicação responsiva de academia, desenvolvida com React, Vite e Capacitor. O projeto funciona como site no computador/celular e como aplicativo Android com notificações locais.

A Academia FitZone é uma academia fictícia criada como parte de um projeto de desenvolvimento de software. Sua proposta é incentivar a prática de atividades físicas e promover uma rotina mais saudável, oferecendo um ambiente moderno, acessível e acolhedor para pessoas que desejam cuidar da saúde e melhorar sua qualidade de vida.

O aplicativo foi desenvolvido para apresentar a academia e oferecer funcionalidades que facilitam a interação dos usuários, incluindo recursos de lembretes e notificações para ajudar na organização da rotina de treinos.

A identidade visual utiliza as cores amarelo, preto e branco, transmitindo energia, movimento e modernidade. A mascote da academia é uma abelhinha, que representa disposição, dedicação e constância.

## Tecnologias
- React + Vite
- CSS responsivo
- Capacitor 8
- `@capacitor/local-notifications`
- GitHub Actions (site e APK)
